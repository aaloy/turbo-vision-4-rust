TURBO VISION RUST - QUICK CODE REFERENCE
========================================

A cheat sheet. The full guide, with compiled examples, the component index and
the rules to follow, is AGENTS.md at the repository root. Dialog layout and
record editors: docs/FORMS.md.


THE APPLICATION SHAPE
=====================

The application owns the event loop. Put your state in a struct, react to
commands in AppHandler::handle_command, and call run_with. Do not write your
own poll loop.

    use turbo_vision::app::{AppHandler, Application};
    use turbo_vision::core::command::{CM_USER, CommandId};
    use turbo_vision::core::event::Event;

    const CM_GREET: CommandId = CM_USER;      // your commands: CM_USER (200) and up

    struct MyApp;

    impl AppHandler for MyApp {
        fn handle_command(&mut self, app: &mut Application, command: CommandId,
                          _: &Event) -> bool {
            match command {
                CM_GREET => { /* ... */ true }
                _ => false,                   // not ours
            }
        }
        // also: pre_event, idle, window_closed
    }

    fn main() -> turbo_vision::core::error::Result<()> {
        let mut app = Application::new()?;
        // app.set_menu_bar(...); app.set_status_line(...);
        app.run_with(&mut MyApp);             // returns on Alt+X / CM_QUIT
        Ok(())
    }


MENU BAR
========

    use turbo_vision::core::menu_data::{Menu, MenuItem, MenuItemBuilder};
    use turbo_vision::views::menu_bar::{MenuBar, SubMenu};

    let (width, height) = app.terminal.size();
    let mut bar = MenuBar::new(Rect::new(0, 0, width, 1));
    bar.add_submenu(SubMenu::new("~F~ile", Menu::from_items(vec![
        MenuItemBuilder::new().text("~O~pen...").command(CM_OPEN).key("Ctrl+O").build(),
        MenuItem::separator(),
        MenuItemBuilder::new().text("E~x~it").command(CM_QUIT).key("Alt+X").build(),
    ])));
    app.set_menu_bar(bar);

A menu item's .key("Ctrl+O") works while the menu is closed too.

    use turbo_vision::core::status_data::StatusItemBuilder;

    app.set_status_line(StatusLine::new(

        ],

A DIALOG OF FIELDS (use Form; no coordinates)
=============================================

    use turbo_vision::views::GroupLike;               // for dialog.get(..)
    use turbo_vision::views::form::{Form, size};

    let mut form = Form::new("Search");
    let text = form.field("~T~ext", InputLine::new(Rect::default(), 80));  // stretches
    let max  = form.field("~M~ax", InputLine::new(size(6, 1), 5));        // 6 columns
    form.ok_cancel();
    let mut dialog = form.build();                    // sized and centred
    if dialog.execute(&mut app) == CM_OK {
        let text = dialog.get(text).map(|f| f.text().to_string());
    }

Lines of fields: form.line(); groups: form.group("Title") .. form.end_group();
labels above: form.label_position(LabelPosition::Above).


EDITING A STRUCT (record forms: typed fields, validation, saving)
=================================================================

    let mut form = Form::<Customer>::for_record("Customer");
    form.input("~N~ame", |c| &mut c.name).required();
    form.input("~A~ge", |c| &mut c.age);              // u32: must be a whole number
    form.check("~V~IP", |c| &mut c.vip);
    form.ok_cancel();
    let mut editor = form.build_editor();
    let edited: Option<Customer> = editor.edit(&mut app, customer);
    // or editor.edit_with(&mut app, customer, |c| db.save(c).map_err(..))


WINDOWS ON THE DESKTOP
======================

    let mut window = Window::new(Rect::new(2, 1, 62, 16), "Log");
    let viewer = window.add_typed(TextViewer::new(Rect::new(0, 0, 58, 13)));
    let window = app.desktop.add_typed(window);       // keep the handles
    // later:
    if let Some(w) = app.desktop.get_mut(window) {
        if let Some(v) = w.get_mut(viewer) { v.set_text("..."); }
    }

A window's children are placed inside its frame: (0, 0) is the inner corner.


ENABLING AND DISABLING COMMANDS
===============================

    app.disable_command(CM_SAVE);   // every Save menu item and button greys out

EVENTS
======

    Event::keyboard(KB_F1)
    Event::command(CM_OK)
    Event::broadcast(CM_COMMAND_SET_CHANGED)
    Event::mouse(EventType::MouseDown, Point::new(x, y), MB_LEFT_BUTTON, false)

    match event.what {
        EventType::Keyboard  => { /* event.key_code, event.typed_char() */ }
        EventType::Command   => { /* event.command */ }
        EventType::Broadcast => { /* event.command; never clear it */ }
        EventType::MouseDown | EventType::MouseUp | EventType::MouseMove => {
            /* event.mouse.pos (view-relative), .buttons, .double_click */
        }
        _ => {}
    }


STANDARD COMMAND CONSTANTS (core::command)
==========================================

Dialogs:   CM_OK 10, CM_CANCEL 11, CM_YES 12, CM_NO 13
App:       CM_QUIT 1, CM_CLOSE 4, CM_ZOOM 5, CM_NEXT 7, CM_PREV 8,
           CM_TILE 25, CM_CASCADE 26
Files:     CM_NEW 30, CM_OPEN 31, CM_SAVE 32, CM_SAVE_AS 33, CM_SAVE_ALL 34,
           CM_CLOSE_FILE 35
Edit:      CM_CUT 20, CM_COPY 21, CM_PASTE 22, CM_UNDO 23, CM_REDO 111,
           CM_SELECT_ALL 115, CM_FIND 116, CM_REPLACE 117, CM_SEARCH_AGAIN 118
Help:      CM_HELP_INDEX 140
Broadcast: CM_RECEIVED_FOCUS 50, CM_RELEASED_FOCUS 51,
           CM_COMMAND_SET_CHANGED 52, CM_IDLE_TICK 123

Numbering: 0-99 Borland's standard commands, 100-199 reserved for the crate,
CM_USER (200) and up for your application. Always use the constants, not the
numbers.


KEY CODE CONSTANTS (core::event)
================================

KB_ESC, KB_ENTER, KB_BACKSPACE, KB_TAB, KB_SHIFT_TAB
KB_F1 .. KB_F12, KB_UP, KB_DOWN, KB_LEFT, KB_RIGHT
KB_HOME, KB_END, KB_PGUP, KB_PGDN, KB_INS, KB_DEL
KB_ALT_A .. KB_ALT_Z, KB_CTRL_A .. KB_CTRL_Z
KB_TEXT: a typed character past U+00FF; the character is in event.ch
alt_code('o') == Some(KB_ALT_O)
In menus and status items, write keys as chords: .key("Ctrl+O"), .key("Alt+X").


RECT AND POINT (core::geometry)
===============================

    let p = Point::new(x, y);
    let r = Rect::new(x1, y1, x2, y2);   // top-left inclusive, bottom-right exclusive
    r.width(); r.height();
    r.contains(p); r.intersects(&other); r.intersect(&other); r.union(&other);
    r.grow(-1, -1);                       // shrink one cell on every side

Positions are relative to the owner view. Rect::default() means "no size":
Form stretches such views to fit.


TILDE (~) HOT KEYS
==================

"~N~ew"        -> N is highlighted; Alt+N in a menu bar, N in an open menu
"~O~K"         -> on a button: Alt+O anywhere in its dialog (plain O too,
                  unless an input line has the focus)
"~N~ame"       -> on a label: Alt+N focuses the linked field
"~Alt-X~ Exit" -> in the status line, the text between tildes is highlighted

Each letter only once per dialog or menu: with two, the first wins.


MODAL DIALOGS
=============

    let command = dialog.execute(&mut app);   // blocks until it closes
    // CM_CANCEL for Cancel, Esc and the close box

Modeless: app.desktop.add(dialog) puts it on the desktop like a window.
